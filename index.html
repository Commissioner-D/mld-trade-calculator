What "value" means here (offense): SCR (from FantasyPros' season stat projections, run through this league's own scoring) plus age and draft-capital adjustments — calibrated against FantasyPros' Dynasty Expert Consensus Rankings. No trailing/past production is used as a fallback. If a player has no stat projection but does have a Dynasty rank, SCR is inferred from that rank instead (via a curve built from players who have both). If a player has neither, he shows NA in red and can't be added to a trade — found, but not guessed at.
IDP and kickers: still run on trailing production (65% current + 35% prior season) — a separate calibration pass for defense is planned but not done yet.
Pick values: calibrated against all 6 real rookie drafts in this league (2020–2025, 480 players). On average, only picks 1–3 of a given class end up above replacement level.
